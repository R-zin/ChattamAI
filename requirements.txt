# OCR (feature-flagged; see plan.md Phase 3). Imported lazily inside app/rag/ocr.py
# and gated by OCR_ENABLED, so installs that only serve text/PDF plans are unaffected.
# Pins chosen to support BOTH Python 3.9 (dev) and 3.12 (CI):
#   - pillow:      10.x supports 3.8–3.12; capped <12 to stay clear of breaking changes.
#   - pytesseract: pure-Python wrapper, requires_python >=3.8 (3.9 & 3.12 OK).
#   - PyMuPDF:     capped <1.27 because 1.27+ bumps requires_python to >=3.10 (drops 3.9);
#                  1.24–1.26 require >=3.9 and ship cp39-abi3 wheels that run on 3.9–3.12.
# NOTE: the Tesseract OCR binary is a SYSTEM requirement, not a pip package:
#   macOS: `brew install tesseract`   Debian/Ubuntu: `apt install tesseract-ocr`
pillow>=10,<12
pytesseract>=0.3.10
PyMuPDF>=1.24,<1.27
